# Реклама PRIME IT: план запуска

Цель — заявки в WhatsApp и звонки из Алматы. Каждая услуга ведёт на свою страницу сайта.

## Файлы

| Файл | Что внутри | Куда |
|---|---|---|
| `google-ads-ads.csv` | 10 групп объявлений: по 12 заголовков и 4 описания | Google Ads Editor → Импорт |
| `google-ads-keywords.csv` | 72 ключевые фразы + минус-слова | Google Ads Editor → Импорт |
| `google-ads-extensions.csv` | Быстрые ссылки, уточнения, звонок | Вносятся вручную в «Ресурсы» |
| `yandex-direct.csv` | Те же 10 групп для Директа | Мастер кампаний / Коммандер |
| `minus-words.txt` | Минус-фразы | Google и Яндекс, на уровне кампании |
| `other-channels.md` | Тексты для Google/Яндекс Карт, 2ГИС, OLX, Instagram, визиток | — |

Тексты меняются в `scripts/ads/ads-data.mjs`, затем `npm run ads` — пересоберёт файлы и проверит
лимиты символов. До подключения домена: `SITE=https://prime-it-1.vercel.app npm run ads`.

## Как сайт понимает, откуда клиент

- Пришёл по рекламе или ссылке с меткой → в сообщении WhatsApp добавляется строка
  «Откуда узнали: Google / Яндекс / 2ГИС / Instagram / OLX …». Работает без cookie.
- Нажатия на WhatsApp и телефон — цели `whatsapp_click` и `phone_click` в Яндекс Метрике и
  Google Analytics 4 (после согласия посетителя на cookie). На них настраивается оптимизация рекламы.

## Настройки Google Ads

1. Аккаунт: **валюта KZT и часовой пояс Алматы** — потом их не изменить.
2. Режим эксперта (не «умная кампания»). Тип: **Поиск**. Цель: «Потенциальные клиенты».
3. Сети: **снять** «Поисковые партнёры» и «Контекстно-медийная сеть».
4. Местоположение: Алматы, вариант «Присутствие: люди, которые находятся в регионе».
5. Языки: русский, казахский, английский.
6. Расписание: ежедневно 07:00–22:00.
7. Бюджет: 3 000 ₸ в день для старта. Стратегия: первые 2 недели — «Максимальное число кликов»
   с ограничением цены клика; после 15–30 заявок — «Максимум конверсий».
8. Автопометка включена (по умолчанию). Настройки аккаунта → «Суффикс конечного URL»:
   `utm_source=google&utm_medium=cpc&utm_campaign={campaignid}&utm_term={keyword}`
9. Связать с Google Analytics 4, импортировать конверсии `whatsapp_click` и `phone_click`.
10. Ресурсы: быстрые ссылки, уточнения и номер телефона из `google-ads-extensions.csv`.
11. Google попросит пройти проверку рекламодателя (документы ИП) — это обычная процедура.

## Настройки Яндекс Директа

1. Тип кампании: «Единая перфоманс-кампания» (или «Текстово-графическая», если доступна),
   площадки — **только поиск** на старте.
2. Регион: Алматы. Расписание: 07:00–22:00. Минус-фразы из `minus-words.txt`.
3. Стратегия: «Максимум кликов», недельный бюджет ~14 000 ₸.
   Когда наберётся 10+ заявок в неделю — «Максимум конверсий» по цели `whatsapp_click`.
4. Подключить счётчик Метрики, цели `whatsapp_click` и `phone_click`.
5. Ссылки в `yandex-direct.csv` уже с метками UTM.

## Бюджет на первый месяц (ориентир)

| Канал | В месяц |
|---|---|
| Google Ads (поиск) | ~90 000 ₸ |
| Яндекс Директ (поиск) | ~60 000 ₸ |
| 2ГИС продвижение | по тарифу 2ГИС |
| Google/Яндекс Карты, OLX, Instagram без рекламы | 0 ₸ |

Это стартовая точка: через 2 недели смотрим, откуда реальные заявки, и переносим деньги
в канал с самой дешёвой заявкой.

## Каждую неделю (15 минут)

1. Google Ads → «Поисковые запросы»: нерелевантные запросы → в минус-слова.
2. Яндекс → «Поисковые запросы» — то же самое.
3. Посчитать заявки в WhatsApp по строке «Откуда узнали».
4. Отключить объявления/ключи, которые тратят деньги без заявок.

## Важно

- Цены в объявлениях должны совпадать с сайтом. Поменяли цену — поменяйте в `ads-data.mjs`.
- Закон РК «О рекламе» требует распространять рекламу на казахском и русском языках.
  Уточните у юриста, как это применяется к интернет-объявлениям; казахские версии текстов
  можно добавить в `ads-data.mjs`.
- Не обещайте в рекламе то, чего нет на сайте (например «лучший», «самый дешёвый»).
