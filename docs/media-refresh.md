# Фотографии, отзывы и desktop-видео

## Что изменилось
- Все 13 фотографий услуг и hero-постер заменены настоящими снимками оборудования с проверенными лицензиями. Это иллюстрации услуг, а не фотографии помещения PRIME IT.
- Одинаковые пропорции карточек, тёмные рамки, умеренная цветокоррекция, alt и два responsive размера.
- Старые PNG удалены из активного дерева. Авторы, ссылки и лицензии сохранены в src/data/media.js; сборка создаёт /photo-credits/ со ссылкой в footer.
- Видео не зависит от наличия ffmpeg на Vercel. Сжатый MP4 H.264/Main, yuv420p, faststart находится в assets/prepared/hero.mp4 (619 034 байта).
- Запуск непосредственно в обработчике клика, нативные controls, loop, загрузка, ошибка и повтор; видео не исчезает после пяти секунд.
- На телефоне остаётся лёгкий постер. Автоматического воспроизведения или загрузки нет, в том числе при reduced motion/saveData.
- Три настоящих отзыва с локальными фото публичных профилей 2GIS, проверенными датами и индивидуальными оценками. Новые портреты не генерировались.

## Проверки
Полный production QA будет записан после завершения CI: npm install, npm run build, static HTML/metadata, Chrome/WebKit на семи размерах, axe и Lighthouse. Дополнительно проверяются успешное проигрывание MP4, ошибка 404 и повтор, наличие всех трёх фото отзывов и одинаковый MP4 в output независимо от окружения сборки.

Защищённый Vercel preview из внешнего runner открывает вход владельца; просмотр там не выдаётся за проверку плеера. Автоматизированные браузерные проверки выполняются на фактическом production output.
