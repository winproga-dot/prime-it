# Админка PRIME IT

Адрес: `/admin/` (например, https://prime-it-1.vercel.app/admin/). Закрыта от поисковиков.

## Что можно менять
Первый экран (заголовок, подзаголовок), жёлтую бегущую ленту, блок «Что случилось», витрину услуг
(4 карточки: тексты, цены, фото), прайс-журнал (13 услуг: название, описание, цена, примечание, фото)
и заголовки разделов. Пустое поле — вернуть текст по умолчанию; пустая цена — «после диагностики».

## Как это работает
1. Вход по паролю → подписанная cookie (HttpOnly, Secure, SameSite=Strict) на 8 часов.
2. «Сохранить и опубликовать» → правки проверяются на сервере и сохраняются в Vercel Blob
   (каждое сохранение — новая версия, хранятся последние 20).
3. Сразу запускается пересборка сайта (Deploy Hook) — через 1–2 минуты изменения видны всем,
   в том числе поисковикам. До этого их можно посмотреть по ссылке «Предпросмотр» (только после входа).
4. «Выйти» удаляет cookie и отзывает все выданные ранее сессии.

## Защита
- Без входа API отдаёт 401: чтение данных админки, сохранение, загрузка файлов.
- Изменяющие запросы принимаются только со своего сайта (заголовок X-Admin-Request + проверка Origin).
- После 5 неверных паролей вход с этого IP блокируется на 15 минут.
- Сервер принимает только известные поля с ограничением длины; изображения — только JPEG/PNG/WebP
  до 5 МБ (формат проверяется по содержимому файла).
- Пароль и секрет хранятся только в переменных окружения Vercel, в коде их нет.

## Настройка в Vercel (один раз)
Project `prime-it-1` → Settings:
1. **Storage → Create → Blob** → подключить к проекту (Production + Preview). Переменная
   `BLOB_READ_WRITE_TOKEN` добавится сама.
2. **Settings → Git → Deploy Hooks** → имя `admin`, ветка `main` → Create → скопировать адрес.
3. **Settings → Environment Variables** (Production):
   - `ADMIN_PASSWORD` — пароль админки (не короче 10 символов, лучше 16+);
   - `SESSION_SECRET` — случайная строка не короче 32 символов
     (например, из `openssl rand -hex 32`);
   - `DEPLOY_HOOK_URL` — адрес из шага 2.
4. **Deployments → Redeploy** последнего деплоя, чтобы переменные применились.

## Локальная проверка
```bash
npm run build
ADMIN_PASSWORD=... SESSION_SECRET=... CONTENT_STORE_DIR=.admin-store node scripts/dev-server.mjs
```
Автотест полного сценария: `npm run qa:admin` (пароль и секрет генерируются случайно).
