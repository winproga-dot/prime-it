# Повторный аудит PRIME IT

Проверена версия 7de0ab89: код, реальная production-сборка и скриншоты главной и страниц услуг. Vercel preview требует входа владельца; доступ внешнего runner через эту защиту не заявляется.

## Подтверждённые проблемы и исправления

| Проблема | Что изменено |
| --- | --- |
| При тексте 200% на 320–390 px появляется горизонтальная прокрутка | Ограничены минимальные размеры grid/flex, добавлены переносы и адаптация карточек под размер текста |
| Содержимое и пояснения на телефоне набраны 10–12 px | Основной текст и FAQ увеличены до 15–16 px, важные пояснения — до 13 px; размеры текста используют rem |
| Маршрут в hero располагается отрицательным margin | Общий ContactActions для главной и услуг: WhatsApp, телефон и маршрут в естественной сетке |
| Переход к разделу «Услуги» сам раскрывает все дополнительные карточки, а FAQ — первый ответ | Автораскрытие осталось только для конкретных старых service/license links и раздела лицензий |
| Tab после открытия меню пропускает его ссылки | Фокус переходит на первую ссылку; Tab идёт по пунктам; Escape возвращает фокус кнопке |
| Меню выходит ниже экрана 1024×320 | Ограничена высота и добавлена вертикальная прокрутка без переноса пунктов в боковые колонки |
| Фиксированные панели рассчитаны на одну высоту | Реальная высота header и мобильной панели измеряется при изменении текста/окна; якоря и нижний отступ используют её |
| FAQ и контакты страницы услуги отправляют общий WhatsApp-текст | Все обращения со страницы сохраняют название услуги; выбранная проблема сохраняется и на главной |
| На странице ремонта ПК показан ноутбук | Используется реальное фото настольного ПК; обновлён также hero-постер |
| Кнопки и цены первой карточки расположены выше остальных | Дополнительная ссылка на ремонт ПК перенесена перед ценой; действия выровнены |
| Новый компьютер получает пояснение о цене после диагностики | Для подбора/продажи указана зависимость цены от модели и комплектации |
| Блок контактов выглядит как карта, но показывает декоративную сетку | Показана понятная карточка с проверенными прямыми ссылками на карту PRIME IT и маршрут в 2GIS |
| Быстрое закрытие видео может дать позднюю ложную ошибку | Отменённые запросы проигрывания не меняют состояние закрытого плеера |
| Правила _redirects не определяют настройки Vercel | Добавлен vercel.json: завершающий slash, нормализация index.html, canonical host, MIME protection и cache для assets |

Цены услуг и реальные условия гарантии сохранены. Отзывы, фотографии авторов и их исходные тексты сохранены; рейтинг бизнеса и новые обещания не добавлялись.

## Проверки

Первичный [визуальный аудит](https://github.com/winproga-dot/prime-it/actions/runs/36933426067) воспроизвёл проблемы с увеличением текста и меню.

Проверяется обновлённая production-сборка:
- npm install, npm run build, static QA всех 11 индексируемых страниц;
- Chromium и WebKit: главная и десять страниц на семи обязательных размерах;
- дополнительные ширины 320, 600, 601, 768, 900 и 1024 px, текст 200%, горизонтальное меню;
- WhatsApp-контекст всех ссылок на страницах услуг, клавиатура меню, видео и его закрытие при незавершённой загрузке;
- отсутствие лишних запросов к внешним виджетам, правильная карточка/маршрут 2GIS, axe и Lighthouse.

Финальные результаты записываются после полного CI. Встраиваемые карты из среды проверки возвращали 429 либо страницу ошибки при HTTP 200. Поэтому использованы прямые ссылки на проверенную карточку и маршрут 2GIS в новом окне; на странице нет зависимого от провайдера iframe или лишних запросов.

## Вне кода

Домен владельца не оплачен: восстановление регистрации и DNS остаётся необходимым для открытия prime-it.kz. После deployment нужны Search Console/sitemap и проверка реальных HTTP-ответов, в том числе deep links и canonical host. В 2GIS следует синхронизировать часы с фактическими 10:00–20:00 без выходных. Запуск приложений WhatsApp/телефона проверяется на физических устройствах.
