# Фото услуг

Все фото услуг (кроме «Сборки ПК» — собственный кадр PRIME IT) сделаны в одном стиле:
реальный предмет вырезан с исходной фотографии и поставлен на одинаковую тёмную «студию»
(мягкий верхний свет, пол, контактная тень, лёгкое отражение, виньетка, зерно).

- Исходники — фотографии с Wikimedia Commons под свободными лицензиями.
  Авторы, ссылки и лицензии — в `src/data/media.js`, они выводятся на странице `/photo-credits/`.
- Готовые кадры 1600×1000 лежат в `assets/photos/<id>.webp`;
  `npm run build` (scripts/prepare-assets.mjs) делает из них размеры для сайта.

## Как сделать новое фото в том же стиле

Нужен Python 3 с `opencv-python-headless` и `numpy`.

```bash
python3 -I scripts/photo-studio.py photos.json out
```

`photos.json` — по одному объекту на услугу:

| Поле | Значение |
|---|---|
| `src` | путь к исходной фотографии |
| `mode` | `plain` — предмет на однотонном фоне (белом, сером, цветном); `alpha` — PNG/WebP с прозрачностью |
| `w`, `h` | максимальная доля ширины/высоты кадра под предмет (обычно 0.6–0.7) |
| `flat`, `tilt` | для снятых строго сверху плоских предметов (SSD, плата): «положить» на стол в перспективе |
| `screen`, `wall` | 4 угла экрана ноутбука (доли ширины/высоты) и заставка: `blue`, `brand` или `{src, quad}` — картинка с другого фото |
| `dx` | сдвиг по горизонтали (доля ширины) |
| `hi`, `lo`, `holes` | настройка вырезания на однотонном фоне |

Лучше всего подходят фото предмета целиком, без обрезки краем кадра, на ровном светлом фоне.
После замены файла обновите автора и лицензию в `src/data/media.js`.
